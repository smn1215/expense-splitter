# Agent Context & Rules

## Technical Stack
- Frontend: HTML5, CSS3, Vanilla JavaScript (Fetch API)
- Backend: Python 3.10+, FastAPI, Uvicorn, SQLite
- Testing: Pytest, HTTPX

## Code Quality & Architecture Rules
1. Follow RESTful conventions for API endpoints.
2. Keep frontend logic minimal, pure Vanilla JS with no external heavy frameworks.
3. Use SQLite as the persistent database via standard library `sqlite3` or `SQLAlchemy`.
4. Ensure all code passes tests run via `pytest`.
